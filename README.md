# MUSE-AI

MUSE-AI is a clean public showcase repository for AI-assisted application architecture and compatibility-first frontend migration notes.

This repository is separate from private production work. It is intended for public documentation, open-source review, and future Codex OSS application material.

## Purpose

- Document safe AI-assisted development workflow.
- Document React and Vite migration practices.
- Provide public project governance files.
- Keep private product work outside this repository.

## Included

- Public overview.
- Security policy.
- AI agent contribution rules.
- Architecture notes.
- Example environment file with placeholder values only.

## Excluded

- Production credentials.
- Real user data.
- Private product history.
- Payment logic.
- Internal prompts.

## Status

Public documentation foundation. Production code has not been imported.
