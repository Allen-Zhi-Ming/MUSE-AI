# Security Policy

## Supported status

This repository is a public documentation foundation. Production services are not deployed from this repository.

## Reporting a security issue

Open a private report through GitHub security advisories if available, or open an issue with non-sensitive details only.

Do not post secrets, tokens, credentials, private user data, or exploit payloads in public issues.

## Public issue rules

- Describe the affected file or document.
- Explain the risk without exposing sensitive material.
- Include safe reproduction steps when possible.
- Do not include real credentials or production URLs.

## Scope

In scope:

- Documentation that could mislead users into insecure deployment.
- Example configuration that could encourage unsafe key handling.
- Agent instructions that could allow destructive changes.

Out of scope:

- Private production repositories.
- Third-party platform outages.
- Social engineering requests.
