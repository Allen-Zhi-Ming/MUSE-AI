# Review Checklist

Use this checklist before publishing any public repository update.

## Scope check

- [ ] The change matches the public scope.
- [ ] The change is small enough to review.
- [ ] The change does not require private project context.

## Documentation check

- [ ] README stays accurate.
- [ ] Related docs use consistent wording.
- [ ] Links and file names are correct.
- [ ] Examples are easy to understand.

## Safety check

- [ ] Examples use placeholder values only.
- [ ] No real user data is included.
- [ ] No production configuration is included.
- [ ] No private repository history is imported.

## Completion check

- [ ] The update has a clear purpose.
- [ ] The change can be verified from the public repo.
- [ ] Any follow-up work is tracked in an issue.
